Was the percent prediction correct?

A sharper test than the hit-rate above: using only price history from before an anchor date ~1 year back, the pipeline computes a median-based expected return at each horizon — then checks it against what actually happened, now that every one of these windows (even the 12-month one) has fully played out. Getting the sign right and getting the number right are different claims; this table checks both.

Same buy-and-hold-drift methodology as the two sections above — not the day-to-day models the rest of this project uses, and not a signal about what's about to happen. "Expected return" is the historical median forward return at this horizon computed from all of this ticker's history to date (median minimizes forecast error, per standard forecasting theory); the hit-rate column is how often that direction has actually been right, out-of-sample, historically. Longer horizons can rest on very few independent samples — check the count before trusting the percentage.
